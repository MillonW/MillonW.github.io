### deploy_api.py 改造为通用版

旧版只能推 main、且文件列表和 commit message 都是硬编码的，复用性差。
新版改进：
- 分支从命令行传：`python deploy_api.py optimize`（默认 main）
- 改动文件改为自动算：`git diff --name-only origin/<branch>..<branch>`
- commit message 从本地最新 commit 取：`git log -1 --pretty=%B <branch>`
- 支持删除文件（本地已不存在的路径，tree entry 用 `sha: null` 表示删除）
- 结束时提示对齐本地历史的方法

用法：
```bash
python .workbuddy/deploy_api.py optimize
```
注意它走的是 GitHub REST API，与 git push 的网络通道不同 —— 
**git push 被代理拦时，API 往往仍然是通的**，这是本项目最可靠的兜底。
