### 1. 鼠标微动抽搐（上一轮自己引入的回归）

### 2. 主题切换生硬且掉帧
根因：View Transitions API + `clip-path` 圆形动画。**clip-path 无法 GPU 加速**，
每帧都要重新光栅化整页快照，再叠加页面里的 mix-blend-mode / backdrop-filter 必然掉帧。

修复：
- 移除 View Transitions，改用 `transform: scale` 的圆形遮罩（`.theme-wipe`，基准 120px）
- 遮罩铺满后加 `.theme-switching` 禁用 transition 再换色，淡出时看到的已是最终配色
- 动画期间 `.is-wiping` 收起 mix-blend-mode 图层降低合成开销

### 4. 首屏视差抽搐（用户反馈）
现象：标题/头像只在首屏区域内滑动才有动画，移出窗口会瞬间抽搐回原位。
根因：监听挂在 `#hero` 上（只在区域内响应）+ `mouseleave` 时把坐标瞬间归零、下一帧直接应用（一帧跳回 = 抽搐）。
修复：`initHeroParallax` 改监听 `window`（整页任意位置响应），坐标改视口归一化，
引入 target→current 缓动（系数 0.1），`mouseleave` 只把 target 归零，由缓动平滑归位，
追上后停 rAF。`.hero__*` 的 CSS transition 只作用于 transform，与 parallax 用的 translate 属性不冲突。
