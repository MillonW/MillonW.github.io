## 关键技术决策

- **3D 倾斜不能直接作用在 `.card`**：`.card` 的 transform 已被入场动画
  （translateY(28px) → none）占用，inline transform 会覆盖它。改作用在内层 `.card__media`
- **首屏视差不能用 transform**：hero 内元素带 `.reveal`，同样冲突。
  改用独立的 `translate` CSS 属性（与 transform 分离，两者叠加不冲突）

## 第 3 轮修复（仅本地，未推送）

备份：`C:\Users\admin\Desktop\millonw-homepage-backup-20260906-0952`

### 1. 鼠标微动抽搐（上一轮自己引入的回归）
根因两条：
- 在 `mousemove` 回调里直接写 transform，与浏览器渲染节奏不同步
- spotlight 用 CSS 变量 `--mx/--my` 驱动 `radial-gradient`，每次移动都使整页样式失效并重绘

修复：
- mousemove 只记坐标，**所有样式写入统一放进 rAF 回调**
- spotlight 结构改为 `<div class="spotlight"><i></i></div>`，固定 840px 的光晕用
  transform 移动，只走合成层，不再重绘渐变
- 微动（位移 < 6px）时收敛系数提到 0.6，消除「动一下、停一下」

### 2. 主题切换生硬且掉帧
根因：View Transitions API + `clip-path` 圆形动画。**clip-path 无法 GPU 加速**，
每帧都要重新光栅化整页快照，再叠加页面里的 mix-blend-mode / backdrop-filter 必然掉帧。

修复：
- 移除 View Transitions，改用 `transform: scale` 的圆形遮罩（`.theme-wipe`，基准 120px）
- 遮罩铺满后加 `.theme-switching` 禁用 transition 再换色，淡出时看到的已是最终配色
- 动画期间 `.is-wiping` 收起 mix-blend-mode 图层降低合成开销

### 3. 彩蛋（4 个，均符合极简黑白风格）
- Konami ↑↑↓↓←→←→BA → 扫描线 + main 抖动
  （**只抖 main**：位移 body 会让所有 fixed 子元素错位）
- 头像连点 3 下 → 反色脉冲环 ×3
- `T` 键 → 切换主题（输入框内不触发）
- 控制台欢迎语 + 彩蛋提示
- reduced-motion 下四个彩蛋全部降级为纯 toast，不做动画

### 4. 首屏视差抽搐（用户反馈）
现象：标题/头像只在首屏区域内滑动才有动画，移出窗口会瞬间抽搐回原位。
根因：监听挂在 `#hero` 上（只在区域内响应）+ `mouseleave` 时把坐标瞬间归零、下一帧直接应用（一帧跳回 = 抽搐）。
修复：`initHeroParallax` 改监听 `window`（整页任意位置响应），坐标改视口归一化，
引入 target→current 缓动（系数 0.1），`mouseleave` 只把 target 归零，由缓动平滑归位，
追上后停 rAF。`.hero__*` 的 CSS transition 只作用于 transform，与 parallax 用的 translate 属性不冲突。
